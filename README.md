# uGNSS Monitor PWA

PWA-приложение для подключения к GNSS через Serial Web API.

## Возможности

- Подключение к GNSS-приёмнику через COM-порт (браузеры на Chromium)
- Отображение позиции, heading, скорости, числа спутников
- Трек с bounding box и масштабированием
- Статистика: DRMS, 2DRMS, 3DRMS, RMS азимута, частота выдачи
- Режим слежения за позицией
- Экспорт: CSV, KML
- Тёмная/светлая темы

## NMEA-сообщения

- `$**RMC` — позиция, скорость, курс
- `$**HDT` — истинный heading
- `$**GGA` — спутники, HDOP, fix type

## Запуск

Открыть `index.html` в Chromium-браузере или развернуть как PWA.
